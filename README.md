# Физика — курс, чат и платформа

Первый каркас платформы подготовки к ОГЭ по физике:

- открытая теория, презентации и задачи;
- peer-to-peer canvas для уроков физики;
- закрытый интенсив с домашними работами и обратной связью.

Сейчас реализована посадочная страница со счётчиком до ОГЭ по физике. Дата
10 июня 2027 года взята из проекта расписания и прямо обозначена на странице как
предварительная.

## Стек сайта

- Astro;
- Tailwind CSS;
- DaisyUI;
- TypeScript.

Интерактивные учебные презентации будут добавляться позднее на стеке из
`TECH_STACK.md`.

## Локальный запуск

Требуется Node.js 24. Версия закреплена в `.nvmrc`.

```bash
nvm use
npm install
npm run dev
```

Проверка и сборка:

```bash
npm run check
npm run build
npm run preview
```

Статическая сборка создаётся в `dist/`.
